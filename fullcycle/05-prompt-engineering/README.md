# Prompt Engineering — material de estudo

Exercícios do MBA sobre instruções, composição de workflows, versionamento, enriquecimento
de consultas e avaliação de respostas.

Cada capítulo declara suas dependências e pode trazer instruções em `AGENTS.md`.
Os exemplos usam versões diferentes de LangChain; mantenha ambientes separados e consulte
o guia de atualização antes de adaptar exemplos à API atual.

A revisão de **19/11/2026** incrementou as dez notas de avaliação comparativa e reuniu
orientações para os demais capítulos. Os exemplos executáveis permanecem como material
do curso; não houve migração automática nem execução de serviços pagos.

Materiais que foram movidos para o repositório externo `ai-tools` não estão presentes nesta
árvore. O antigo caminho `desafio/` também não existe aqui; os enunciados locais estão em
[03 — Desafios técnicos](../03-challenges-tech/).
