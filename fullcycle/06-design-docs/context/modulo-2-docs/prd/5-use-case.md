# Continuação: escolher a documentação do fluxo de login

Esta nota repetia integralmente [4-use-case.md](4-use-case.md). A explicação e as imagens
foram mantidas nessa referência; esta continuação acrescenta um exercício de aplicação.

## Exercício proposto

Considere um produto que usa login básico e agora recebe um cliente corporativo com SSO.
Registre o público afetado, o comportamento atual, a mudança desejada e os limites de escopo.
Separe requisitos confirmados, propostas e dúvidas: recuperação de conta, vinculação de
identidade, isolamento entre tenants e desligamento do colaborador não devem virar decisões
implícitas.

Escolha então a documentação proporcional. Um PRD de feature pode esclarecer o resultado
para produto; um ADR pode justificar o mecanismo de identidade; o contrato e os cenários
de autorização precisam permitir testar o comportamento. Não é obrigatório produzir todos
os documentos: explique qual dúvida cada artefato escolhido resolve.
