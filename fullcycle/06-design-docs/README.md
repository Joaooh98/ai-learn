# Design docs — material de estudo

Ensaios e anotações produzidos no MBA. Estes arquivos estudam a documentação como ativo de
engenharia e não descrevem uma ferramenta em execução.

| Módulo | Tema |
|---|---|
| `context/modulo-1-intro/` | História, RUP, Agile e problemas conhecidos de documentação |
| `context/modulo-2-docs/` | Documentação na era da IA, taxonomia e PRDs |
| `context/modulo-3-design-and-arquiteture/` | Design docs, arquitetura, high level e feature design |

O antigo plano de adoção de skills foi movido para `research/` no repositório `ai-tools`, pois
documenta uma decisão da ferramenta e não uma aula.
